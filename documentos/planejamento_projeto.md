# Planejamento do Projeto

## Título

Análise da Pesquisa Kaggle sobre Profissionais de Dados

## Objetivos

Identificar quais as:
- Ferramentas
- Linguagens
- Habilidades
mais utilizadas por profissionais da área de dados, analisando padrões presentes no dataset do Kaggle sobre Machine Learning e Ciência de Dados.

## Dataset

**Nome:** 2022 Kaggle Machine Learning & Data Science Survey

**Fonte:** Kaggle

**Descrição:**
Pesquisa anual realizada pelo Kaggle sobre o cenário de Machine Learning e Ciência de Dados. O dataset contém respostas de profissionais e estudantes da área, incluindo informações sobre cargos, experiência, linguagens de programação, ferramentas utilizadas e outros aspectos relacionados ao trabalho com dados.
Após o processo de limpeza realizado pelo Kaggle, o dataset possui 23.997 respostas.

**Arquivo utilizado:**
kaggle_survey_2022_responses.csv

**Arquivos auxiliares:**
kaggle_survey_2022_answer_choices.pdf
kaggle_survey_2022_methodology.pdf

**Link:**
https://www.kaggle.com/c/kaggle-survey-2022

## Perguntas

1. Quais linguagens são mais utilizadas por profissionais da área de dados?
2. Quais ferramentas e habilidades aparecem com maior frequência?
3. Existem diferenças no uso de ferramentas entre diferentes cargos da área de dados?
4. Como a experiência influencia o uso das tecnologias?

## Tecnologias

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Etapas do Projeto

1. Carregamento e entendimento dos dados
2. Análise da estrutura do dataset
3. Tratamento e limpeza dos dados
4. Análise exploratória dos dados (EDA)
5. Criação de visualizações
6. Interpretação dos resultados
7. Documentação final

## Resultados Esperados

Obter uma visão geral sobre as tecnologias mais utilizadas na área de dados e identificar possíveis diferenças entre profissionais de diferentes cargos e níveis de experiência.
