# Análise da Pesquisa Kaggle sobre Profissionais de Dados

## Sobre o projeto

Projeto de análise exploratória de dados utilizando a pesquisa Kaggle ML & DS Survey 2022.

O objetivo é identificar ferramentas, linguagens de programação e habilidades mais utilizadas por profissionais da área de dados.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
