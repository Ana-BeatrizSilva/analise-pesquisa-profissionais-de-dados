## Sobre o Projeto

Projeto de análise exploratória de dados utilizando a pesquisa **Kaggle ML & DS Survey 2022**.

O objetivo é identificar ferramentas, linguagens de programação e habilidades mais utilizadas por profissionais da área de dados, além de investigar possíveis diferenças entre cargos e níveis de experiência.

Foi desenvolvido com finalidade educacional e de portfólio, com o objetivo de praticar e consolidar conhecimentos em manipulação de dados, análise exploratória e visualização de dados.
